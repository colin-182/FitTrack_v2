FitTrack — Gym & Fitness Tracker

Users — profile, contact details, profile pic
WorkoutPlans — name, description, start/end dates, status, assigned trainer (stakeholders)
WorkoutLogs — exercise, sets, reps, weight, date
Messages — sender, receiver, body, archived flag
Categories — cardio, strength, flexibility, etc.

Core Features mapped to the rubric:

User Management — register, login, update profile, forgot password via email
Data Storage — log workouts, categorise them, track progress
Inbox — users message their trainer, archive old messages
User Roles — member vs trainer role, trainers can create plans and view their clients' logs — this directly hits the auth/permissions criterion

UI Ideas (Bootstrap):

Dashboard with progress stats and a streak counter
Calendar view of workouts
Charts showing weight lifted over time (great JavaScript opportunity)
Collapsible workout log sections
